# Лабораторная работа №2. Оформление страницы с помощью CSS
 
## Цель работы
 
Освоить оформление веб-страницы с помощью внешнего CSS-файла, CSS-переменных, псевдоклассов состояний, позиционирования и современных визуальных эффектов (backdrop-filter).

## Описание проекта
 
Страница «О себе», оформленная преимущественно с помощью внешнего файла стилей `style.css`, с добавлением эффекта матового стекла и интерактивных состояний элементов.
 
## Структура страницы
 
- `<header>` - шапка с именем студента и заголовком страницы
- `<main>` - основной контент страницы
- `<section>` «Навыки» - маркированный список исследовательских и аналитических навыков
- `<section>` «Проекты» - нумерованный список из 4 гипотез/исследований, оформленный карточками
- `<section>` «Фотография» - изображение с атрибутами src, alt, width, height
- `<section>` «Обратная связь» - форма с полями «Имя», «Email», «Сообщение» и кнопкой отправки
- `<aside>` - боковая панель с эффектом «матового стекла» (backdrop-filter: blur)
- `<footer>` - подвал с копирайтом и годом
## Цветовая гамма
 
Академический стиль: основной цвет - светло-голубой (`--color-primary`), акцентный - тёмно-синий (`--color-accent`). Цвета заданы через CSS-переменные в `:root` и используются во внешнем файле `style.css`.
 
## Реализованные требования
 
- Основной стиль - во внешнем файле `style.css`
- Inline-стиль: `opacity: 0.9` на форме обратной связи
- Внутренний блок `<style>`: оформление заголовков (цвет и тень)
- CSS-переменные в `:root` для цветов и шрифтов
- Эффект «матового стекла» на блоке `<aside>`
- При `:hover` на карточках проектов - свечение изнутри
- При `:active` на карточках проектов - изменение прозрачности
- Состояния `:hover`, `:active`, `:focus` для полей формы и кнопки
